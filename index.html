Defense Mapping: Enforce 2FA/MFA, eliminate password reuse, and disable router UPnP.
T1486 / T1204 Ransomware Syndicates (LockBit/BlackCat)
EVALUATING

Syndicates weaponize unpatched zero-day vulnerabilities in operating systems and office macro loaders to achieve kernel privilege escalation and encrypt localized drive storage.

Defense Mapping: Automated 14-day OS patching, 3-2-1 offline backups, and macro block policies.
T1557 / T1040 Adversary-in-the-Middle (AiTM)
EVALUATING

Actors deploy rogue access points ("Evil Twin") in public venues and probe default router administrative passwords to poison local DNS cache and capture session tokens.

Defense Mapping: Continuous VPN routing on public Wi-Fi, DNS-over-HTTPS, and modified router credentials.
T1195 / T1539 Infostealer & Supply Chain Malware
EVALUATING
